# Radioactive Pink Theme for Opencode

A neon pink/magenta aesthetic theme for [Opencode](https://opencode.ai).

## Installation

1. Create the themes directory:
```bash
mkdir -p ~/.config/opencode/themes
```

2. Copy the theme file:
```bash
curl -o ~/.config/opencode/themes/radioactive-pink.json \
  https://raw.githubusercontent.com/Tanwyhang/radioactive-pink-opencode/main/radioactive-pink.json
```

Or if you cloned the repo manually:
```bash
cp radioactive-pink.json ~/.config/opencode/themes/
```

## Activating the Theme

Restart Opencode, then select the theme via the command palette or config:

```json
{
  "theme": "radioactive-pink"
}
```

## Theme Preview

- **Background**: Dark grey (#1a1a1a)
- **Text**: Pale pink (#FFBBEE)
- **Primary**: Hot pink (#FF66CC)
- **Secondary**: Magenta (#FF00FF)
- **Accent**: Coral (#FF9966)
